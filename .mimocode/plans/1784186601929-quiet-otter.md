# Fix Slow Image Loading Across the Website

## Root Cause

All content thumbnails use `picsum.photos` — a free third-party placeholder image service. This service is:
- **Slow from Nigeria/Africa** (high latency, 2-5s+ load times)
- **Unreliable** (frequent timeouts)
- **No caching headers** (re-downloads every time)
- **Returns random images** (not actual content)

All avatars use `ui-avatars.com` — another slow third-party service.

## Files to Modify

### 1. Seed Data — Replace picsum.photos with faster alternatives
- `scripts/demo-content/migrations/002_seed_demo_data.sql` (30 content thumbnails)
- `scripts/database/seed-all.sh` (avatar URLs)

### 2. Frontend — Add image optimization
- `apps/web/src/components/OptimizedImage.tsx` (add fallback, error handling)
- `apps/web/next.config.js` (add image optimization config)

### 3. Backend — Add image caching headers
- `services/gateway/api-gateway/src/modules/proxy/proxy.controller.ts` (add cache headers for images)

## Implementation Plan

### Step 1: Replace picsum.photos URLs in seed data

Replace all `https://picsum.photos/seed/*/800/450` URLs with `https://placehold.co/800x450/1a1a1a/ffffff?text=Content+Title` (faster, more reliable) or use actual S3-hosted images.

**File**: `scripts/demo-content/migrations/002_seed_demo_data.sql`
- Replace 30 `picsum.photos` thumbnail URLs with `placehold.co` URLs
- Add unique text labels per content item for better UX

**File**: `scripts/database/seed-all.sh`
- Update avatar URLs to use `placehold.co` instead of `ui-avatars.com`

### Step 2: Add image optimization to OptimizedImage component

**File**: `apps/web/src/components/OptimizedImage.tsx`
- Add error handling with fallback placeholder
- Add `unoptimized` prop for external images (bypasses Next.js optimization which adds latency)
- Add `onError` handler to show fallback on timeout

### Step 3: Update Next.js image config

**File**: `apps/web/next.config.js`
- Add `placehold.co` to `remotePatterns`
- Add `deviceSizes` and `imageSizes` for responsive images
- Add `minimumCacheTTL` for image caching

### Step 4: Add cache headers for images in gateway

**File**: `services/gateway/api-gateway/src/modules/proxy/proxy.controller.ts`
- Add `Cache-Control: public, max-age=31536000, immutable` for image responses
- This ensures images are cached by the browser and CDN
