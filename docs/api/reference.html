Authentication

All authenticated endpoints require a Bearer token in the Authorization header.

POST /v1/auth/register

Register a new user account.

{
  "email": "user@example.com",
  "password": "securepassword",
  "username": "johndoe"
}

NameTypeRequiredDescription
